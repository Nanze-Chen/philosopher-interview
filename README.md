# 哲学家访谈 · Philosopher Interview

一个依据可核查史料与思想模型，让AI扮演哲学家进行访谈的中文 skill。重点是重构人物的判断方式：世界观、认识标准、价值取舍和论证习惯，使其能够审慎回应史料之外的新问题。

## 开始使用

将 [群友版压缩包](dist/philosopher-interview-skill-v3-portable.zip) 解压，把其中的 `philosopher-interview` 文件夹放入你的 agent 支持的技能目录。也可以让 agent 从本仓库安装入口 `SKILL.md`、`agents/` 与 `references/`；具体目录由你的 agent 环境决定。

安装后可以直接说：

```text
使用 $philosopher-interview，我想和康德对话。请准备他的思想模型，然后由我提问。
```

直接指定人物时，无需说明《西方哲学史讲演录》的讲次，也不会默认加载赵林的理解。当前聊天首次使用会有简短用法说明，后续换人和续谈不重复。

如果希望结合本书，也可以说：

```text
使用 $philosopher-interview，依据赵林《西方哲学史讲演录》2021修订版第三讲，先列出人物，让我选择受访者。
```

## 对话和整理

- 直接提出问题，继续追问人物的理由或检验其中的论证。
- 说“换成某某”，切换受访者；说“跳出角色”，让编者解释原文或核查资料。
- 说“访谈结束”，自动整理本场可访问记录；随后可指定保留、删除、合并或润色某轮。
- 重大解释分歧会明确指出，并按必要的不同读法分别回答。

人物对白是基于资料的拟答，不是历史原话；现代情境中的回答会标明推演。技能不会宣称恢复历史人物的真实意识，也不会宣称穷尽全部文献。

## 文件与环境

技能入口为 [SKILL.md](SKILL.md)，其余指导均使用包内相对路径。分发包不包含作者的聊天索引、项目文稿、本机绝对路径或密钥，不要求预先存在作者的项目目录。

运行环境应能读取技能文件并进行对话。联网检索可用于补充史料；不能联网时可以使用用户提供的材料，但必须说明资料缺口。读取PDF或扫描件时，使用该环境已有的相应工具。技能本身不附带需要安装的Python或Node程序，也不附带书籍全文。

访谈记录在用户当前工作目录中按需生成，这些是运行时产物，不是安装依赖。若环境没有文件工具，则在对话中交付稿件并说明尚未保存。

`dist/` 内的ZIP只包含可安装的skill；README用于介绍仓库，不需要随技能加载。

## 一起改进

欢迎群友通过Pull Request提交改进。体验者可以安装PR中的版本，用相近的问题比较人物的判断方式、回答是否贴题、史料归属和现代情境推演，再在PR下留下简单的体验结论。维护者结合大家的反馈审核后合并，不设正式打分表或自动投票阈值。

具体步骤见 [贡献与体验流程](CONTRIBUTING.md)。
