# 思想模型与情境推演

## 重构一种判断方式

“知道他讲过什么”和“能够依据他的思想回应”是两种能力。前者需要材料索引；后者需要解释同一组前提为何在不同问题中产生有关联的判断。模型应当允许追问、反例和不确定性，不能是一张固定话术卡。

用最少且有依据的约束建立人物，不追求把每一栏填满。资料不足的古代人物，可能只有认识论、本体论和少量生活实践可重构；这比虚构完整人格更可靠。

| 维度 | 要记录的内容 | 失真的常见方式 |
| --- | --- | --- |
| 问题意识 | 他试图解释的难题、针对的前提、为何这值得追问 | 罗列学说而不知道它在回答什么 |
| 世界与人的位置 | 什么具有实在性，变化、秩序、因果、灵魂或社会关系如何理解 | 把一条口号扩展成无所不包的体系 |
| 认识标准 | 怎样才算有理由相信；经验、推理、传统等发生冲突时怎样处理 | 所有人都用当代常识作最终裁决 |
| 价值与生活 | 有材料支持的善、目的、义务、修养及其关联 | 从“世界有秩序”直接推出“必须服从所有权威” |
| 价值冲突 | 哪些代价愿意承担，哪些条件会改变选择；证据不够就保留空白 | 任意给价值观排序或用现代自由主义补齐 |
| 论证习惯 | 归谬、概念辨析、例证、观察、演绎等实际使用方式 | 每个人都只讲比喻或劝人保持平衡 |
| 概念边界 | 核心术语的含义、不同用法、不能混同的邻近概念 | 回答质疑时悄悄更换定义 |
| 限度与张力 | 无法充分证明的环节、难以兼容的材料、缺少的立场 | 把人物写成永不犯错的完美思想家 |
| 发言方式 | 从上述结构自然形成的关注顺序、例子与反问方式 | 无证据地规定傲慢、暴躁、恐惧或童年创伤 |

每个条目带主张ID、来源位置、归属和支持程度。需要不同历史时期、作品阶段或学派层次时建立明确版本，不把变化的思想熔成一个恒常人格。

至少写出一组能够复查的关系：“他主张什么；依赖哪个前提；使用什么理由；这不能推出什么；遇到哪种反例要重新检查”。这是简短论证说明，不要求展示内部思考轨迹。

## 分清三种可说的话

1. **有文献依据的主张重构**：内容可定位，但自然对白仍是拟写。不能把拟写句子加引号当原话。
2. **基于思想的解释性重构**：把多条材料连接成一种理解；注明连接由谁提出，尤其不要把现代研究的解释伪装成无争议原义。
3. **新情境推演**：面对互联网、工作选择、AI等当时没有的情境，基于前提作条件回应。必须有可说明的思想桥梁，但不要求史料里早就有这个答案。

三者可以出现在同一次回答里，按主张分别记录。回答中有两条可靠史实，并不会让夹在中间的现代推演也变成史实。人物口吻的坚定程度不能改变证据等级。

## 新问题怎样转成可回答的问题

先理解用户真正要求的判断及会改变它的事实。例如“要不要用推荐算法？”可能同时指省时间、交出选择权、商业激励或审美塑造。只澄清决定本题的歧义，不先盘问全部背景。

历史人物通过用户介绍认识新对象。用户说“短视频会连续推送我爱看的片段”，人物可以据此讨论欲望和习惯；无需假装懂训练架构。涉及当代产品的真实行为或研究结论，须由编者查证后介绍，或者明确按用户给出的假设讨论。

把新情境接到有证据的概念与实践上，同时写清推演新增的假设：

- 已有依据：人物用什么标准评价某类行为。
- 新情境事实：本题在什么条件下与那类行为相似。
- 推演结论：因此可能如何判断；哪些条件变化会改变它。

这份简短说明保存在档案或轮次注中。对白应自然回答“会怎么看、为什么、会怎样选择”，不机械朗读方法表。

不把事实描述自动变成规范结论：即使一位哲学家认为宇宙和谐，也还需要有证据支持他把和谐用于生活，才可以据此谈人的欲望；更不能直接宣布某个现代制度是他的政治理想。

## 证据强弱决定答到哪里

| 情况 | 合适回应 |
| --- | --- |
| 现成原则与本题联系明确 | 给立场、关键理由、必要条件；标明现代应用是推演 |
| 原则明确，但情境事实不明 | 给条件答案，或只询问决定选择的一项事实 |
| 几条可靠原则在本题相冲突 | 呈现取舍，说明哪一条有更明确依据；无证据排序就不替他排序 |
| 多种解释都能产生合理答案 | 分别说明“若从A出发／若从B出发”；不把两种可能捏成一个唯一历史答案 |
| 没有可靠材料连接本题 | 说清不能归属于本人；可在用户愿意时由现代讲解者另谈，身份分开 |

不能用“他没见过手机”结束所有现代问题，也不能每个问题都硬接学说。推演空间在证据约束内，具有不确定性但仍能有具体内容。

## 在反驳中保持人物

用户说“这不证明你的结论”，就解释理由究竟支持到哪一步；不要换一个更漂亮的例子假装问题已解决。用户给出现代解释时，可以暂按其描述检验；现代解释不自动成为人物的原有理论。

区分三种变化：

- **澄清误解**：解释同一个主张，不能暗中换定义。
- **暂时接受对方假设**：说明是在检验假设，不改写人物核心立场。
- **证据或推演修正**：由编者说明前答何处归属过强、理由不足或年代错误；更新档案与受影响的轮次注。不要为了角色不败而隐藏纠正。

人物可以坚持一个当代读者不接受的前提。保留史料支持的宗教性、等级观或其他时代局限，必要时由编者作语境说明；不能把历史立场自动变成今天对用户的指令。遇到现实医疗、法律等高风险决策，由编者明确区分历史讨论与当前事实依据。

## 发言前的短检查

- 换成另一位哲学家的名字，这个回答仍几乎不变吗？如果是，找到本人物实际采用的判断标准；不要只添加几个专有名词。
- 我是不是把个人、学派、赵林、后世解释或现代推演混为一谈了？
- 这句结论真的从所用理由得出吗？是否依赖了没说明的价值前提？
- 我有没有一边回答一边偷换概念，或对同一个前提作相反判断？
- 我有没有为了赞同用户，抹掉人物真正会坚持的分歧？
- 当前疑点答清楚了吗？删掉复述、人物简介和预告后，是否更直接？

准备访谈时用一个贴近原典的问题、一个强反例和一个现代情境检查模型即可；检查不是让用户等待所有背景知识都加载完。后续实问发现新问题，再补材料和模型。
