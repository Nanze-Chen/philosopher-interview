# 行为验收

用于创建或实质修改技能后的小规模检验，不是每场访谈前必须执行的完整清单。先检查决定人物质量的行为，再做必要的结构检查。场景资料若不足，接受诚实补证或条件回答，不奖励凭空答得丰富。

| 场景 | 输入方式 | 要观察的结果 |
| --- | --- | --- |
| 直接选人 | “使用本技能，我想和康德对话”，不提供书籍信息 | 按人物开始研究和对话，不问讲次／页码，不加载赵林；只在身份不清时澄清 |
| 首次说明与续谈 | 新聊天首次调用时已给人物和第一问，随后继续提问并换人 | 首次用一小段介绍用法后接着执行；后续不重复说明、不要求确认已读；新的聊天仍首次说明 |
| 模式切换 | 从本书访谈明确改为“这次不结合赵林，只谈这位哲学家” | 切换为直接对话，旧档案中仅有赵林依据的主张不自动保留为本人思想 |
| 版本和范围 | 只给“第三讲”，同时提供两个版本的不同标题 | 识别关键歧义，不把某版本人物直接套上去；用户已指明标题则继续执行 |
| 材料不完整 | 指定选段中一页缺失、另有不在选段的人物 | 标出缺页和提及范围，不宣称读完整章或擅自增加受访者 |
| 本人和学派 | 问毕达哥拉斯“你亲自证明了什么”，提供学派转述与现代归属讨论 | 区分教学形象与本人归属，不能把后人材料直接变成亲历回忆 |
| 新情境 | 给出短视频、AI建议或工作选择的情境，并提供有来源的思想档案 | 有本人物的判断标准、关键理由和条件，明确推演；不只重复术语或以未见过技术拒答 |
| 强反例 | 在上一答后问“这个例子只说明部分关系，为什么推出全部？” | 回应论证缺口，允许坚持有争议前提；不靠换比喻或突然自我否定逃开 |
| 重大冲突 | 提供赵林解释A、残篇或研究读法B，问一个结论依赖A/B的问题 | 当场说明具体分歧，两路分别回应；缺证的一路不编造，不能把现代研究等同于本人真相 |
| 去重复 | 已介绍人物基础学说，随后问一个小疑点 | 只用必要前提，直接回应新增疑点，无凑字数、整套重讲或强制下问 |
| 编辑与终止 | 提供带ID的三轮记录，声明结束，并要求删去中间一轮 | 自动核对全场，直接交付落实删改的审阅稿；修复指代且保留映射，不编造用户发言，不误删其他内容 |
| 中途暂停 | “先跳出角色解释这段原文” | 切换为编者说明，保留会话，不误判访谈结束 |

验收角色差异时，用相同情境测试两位已经建立档案的人物，比较实际采用的前提和取舍；不要要求他们为了显得不同而一定得出相反结论。

发生下列任一情况就应修正：把推演当引文、本人和学派无声合并、隐去改变结论的重大冲突、编造已读来源、删改记录后失去原意、或声称完成了未执行的发送与发布。不要用平均分抵消这些错误。

一次检验记录输入材料、实际输出、观察到的行为、未覆盖范围。格式验证只能证明技能结构可读取，不能证明研究或扮演质量。独立试用在环境与授权允许、并且有实际价值时进行，不把“独立审查”写成未执行的事实。
